# Gaussian Elimination

## Definition
It is a systematic method of solving a system of linear equations by converting its augmented matrix into an upper triangular form.

## Why do we use it?
It's easier to solve a large number of equations having unknowns variables which becomes difficult and time consuming to solve by substitution.

## What is an upper triangular matrix?
It is a matrix where every element below each pivot is 0.

## Why can't a pivot be 0?
Because Gaussian Elimination requires dividing by the pivot to calculate the row multiplier. Division by zero is undefined, so we swap rows to obtain a non-zero pivot.

## 3 legal moves aka row operations
1. Swap - Exchange two rows
2. Scale - Multiply a row by a non-zero constant
3. Replace - Add/Subtract a multiple of one row to another

These operations do not change the solution of the system and are used to convert the matrix into upper triangular form.

## Multiplier

The multiplier is calculated by dividing the element below the pivot by the pivot element.

Formula:
Multiplier = (Element below Pivot) / (Pivot)

It is used to eliminate the elements below the pivot by performing row operations.

## Back Substitution

After obtaining the upper triangular matrix, solve the variables starting from the last row and substitute the values into the equations above until all variables are found.

## Worked Example

Given:

        2x + y = 5
        4x + 3y = 11

Augmented Matrix:

        [2 1 | 5]
        [4 3 | 11]

Pivot = 2

    Multiplier = 4/2 = 2

Row Operation:

    R2 -> R2 - 2R1

New Matrix:

        [2 1 | 5]
        [0 1 | 1]

## Algorithm (High Level)

1. Convert the system of equations into an augmented matrix.
2. Select the first pivot.
3. If the pivot is zero, swap rows.
4. Calculate the multiplier for each row below the pivot.
5. Apply row operations to make the elements below the pivot zero.
6. Move to the next pivot and repeat.
7. Continue until an upper triangular matrix is obtained.
8. Use back substitution to find the values of the variables.

## Pseudocode
```
Read matrix.

For every pivot:

    If pivot is zero:
        Swap rows.

    For every row below:
        Calculate multiplier.

        Update row.

Print matrix.
```
# Linear Dependence and Independence
## Definition
Linearly independent vectors contain no redundancy, meaning no vector in the set can be written as a combination of the others, whereas linearly dependent vectors contain extra, redundant vectors.

## Algorithm
Algorithm:
1. User enters matrix
2. We do Gaussian elimination 
3. Generate Final Matrix
4. Check whether the no. of pivots == no. of vectors.
5. If yes then independent and if no then dependent.

# Span, Basis and Dimension
## Definition
Span = The set of all points that can be reached by taking linear combinations of the given vectors.
The remaining set of vectors after removing unnecessary or dependent vectors is known as basis.
And the number of basis is known as dimension.

## Algorithm

- Step 1: Store the original vectors.
- Step 2: Perform Gaussian elimination while keeping track of which original vector each row came from.
- Step 3: Identify the pivot rows.
- Step 4: The original vectors corresponding to those pivot rows form the basis.
- Step 5: Count the pivots.
- dimension = pivot_count
- Step 6: Determine the span from the dimension and the ambient space.

## Pseudocode
```
START

Read number of vectors and their components

original_vectors = input vectors

Perform Gaussian elimination

pivot_count = 0
basis = []

FOR each pivot found:

    pivot_count += 1

    identify the original vector responsible
    for that pivot

    add that original vector to basis

dimension = pivot_count

IF basis spans the entire ambient space:
    span = R^n
ELSE:
    span = subspace generated by basis

RETURN span, basis, dimension

END
```

# Kernel and Image
## Defiinition
Linear Mapping: A function that transforms vectors into other vectors.

Kernel: All input vectors that are transformed into the zero vector.

Image: All output vectors that can be produced by the transformation.

## Algorithm

- Kernel Algo

Goal: Find all vectors that are mapped to the zero vector.

1. Take the matrix A.
2. Set up the equation:
      Ax=0
3. Identify the pivot variables.
4. Identify the free variables.
5. Express the pivot variables in terms of the free variables.
6. Assign convenient values to the free variables.
7. Obtain the vectors that generate all solutions.
8. These vectors form a basis for the kernel.
9. The number of these basis vectors is the dimension of the kernel, called nullity.

- Image Algo

Goal: Find all possible output vectors.

1. Take the matrix A.
2. Look at its columns.
3. Perform Gaussian elimination to determine which columns are pivot columns.
4. Record the corresponding original columns.
5. Those original columns form a basis for the image.
6. The span of those columns is the image/column space.
7. Count the basis vectors.
8. That count is the dimension of the image, called rank.

## Pseudocode

- KERNEL

FUNCTION find_kernel(matrix):

    Make a copy of matrix

    Perform Gaussian elimination

    Identify pivot columns

    Identify free columns

    FOR each free variable:

        Assign it a value

        Solve pivot variables in terms of free variables

        Create a solution vector

        Add solution vector to kernel basis

    RETURN kernel basis

- IMAGE

FUNCTION find_image(matrix):

    Make a copy of matrix

    Perform Gaussian elimination

    Find pivot columns

    FOR each pivot column:

        Take the corresponding column
        from the ORIGINAL matrix

        Add it to image basis

    RETURN image basis

## Key Difference
The Key Difference

KERNEL
A x = 0
   ↓
Solve for INPUT vectors
   ↓
Basis of Kernel

While,

IMAGE
Look at COLUMNS of A
   ↓
Find independent columns
   ↓
Basis of Image

Then,

Rank = dim(Image)
Nullity = dim(Kernel)

- ⚠️ One important limitation
This simple version assumes the matrix is being treated as a homogeneous system Ax=0, which is exactly what we want for the kernel.

# Characteristic Polynomial
## Definition
The characteristic polynomial of a square matrix A is obtained from the determinant of A - λI.

The formula is:
p(λ) = det(A - λI)
```
Here:
A = our matrix
λ = variable
I = identity matrix of the same size
p(λ) = characteristic polynomial
```

# Gram Schmidt
## Definition
Gram-Schmidt takes normal vectors and rebuilds them into perpendicular vectors without changing the space they span.

So the basic idea is:

Take a vector, remove the parts pointing in directions we've already used, and what's left becomes a new perpendicular direction.

## Goal

Given a set of linearly independent vectors:
we want to produce:
v1, v2,........, vn

- an orthogonal set 
 u1, u2,........, un
- an orthonormal set 
e1, e2,........, en
while keeping the same span.

## Algorithm

Step 1: Take the first vector
The first vector doesn't have anything to remove.
u1 = v1

Step 2: Take the next vector
For every new vector vk, look at all the previously created orthogonal vectors.

Step 3: Calculate the projection
For each previous uj,
Proj uj(vk) = vk • uj / uj • uj * uj

Step 4: Subtract all projections
In simple words,
Take the original vector and remove everything pointing in directions we've already created.

Step 5: Repeat
Do this for every vector.
These are orthogonal.

Step 6: Normalize
Find the length of every ui,
||ui|| = \/ u²i1 + u²i2 + .....

Then divide :
ei = ui/ ||ui||

Now:
e1, e2,......, en are orthonormal.

## Whole Algo in one line
Take each vector, remove its projections onto all previously created vectors, store what's left, then normalize everything.

## Pseudcode

GRAM_SCHMIDT(vectors)

INPUT:
    A set of linearly independent vectors

OUTPUT:
    Orthogonal vectors
    Orthonormal vectors
    Steps

1. Create an empty list U
2. Create an empty list E
3. Create an empty list STEPS

4. FOR each vector v in vectors:

       u = v

       FOR each previous vector prev_u in U:

           projection =
               (dot(v, prev_u) / dot(prev_u, prev_u))
               × prev_u

           u = u - projection

           Record projection step

       Add u to U

       Record the new orthogonal vector

5. FOR each vector u in U:

       length = norm(u)

       e = u / length

       Add e to E

       Record normalization step

6. RETURN U, E, STEPS
