# Linear Algebra Solver Website

## Project Overview

The Linear Algebra Solver Website is an educational web application designed to solve linear algebra problems using different mathematical methods. It accepts matrix and vector inputs and provides step-by-step calculations to help users follow the solution process.

The project combines mathematical problem-solving with web development to make selected linear algebra operations easier to perform and understand.

## Features

- **Gaussian Elimination:** Solves systems of linear equations.
- **Linear Dependence and Independence:** Analyzes relationships between vectors.
- **Span, Basis, and Dimension:** Supports problems involving vector spaces and their properties.
- **Kernel and Image:** Handles calculations related to the kernel and image of a linear transformation.
- **Characteristic Polynomial:** Calculates the characteristic polynomial of a matrix.
- **Gram-Schmidt Process:** Supports the construction of orthogonal and orthonormal vectors.
- **Step-by-Step Solutions:** Displays calculation steps to make the solving process easier to follow.

## Technologies Used

- **Python:** Implements the mathematical solving logic.
- **Flask:** Connects the backend solving modules to the web application.
- **HTML:** Structures the web pages.
- **CSS:** Styles the user interface.
- **JavaScript:** Supports frontend functionality.
